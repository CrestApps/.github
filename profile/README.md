# CrestApps

Open-source building blocks for .NET and Orchard Core: AI frameworks, agent tooling, CMS modules and developer utilities.

[![Sponsor](https://img.shields.io/badge/Sponsor-%E2%9D%A4-db61a2?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/MikeAlhayek)
[![Website](https://img.shields.io/badge/Website-crestapps.com-0969da)](https://crestapps.com)

## Projects

| Project | What it does |
|---|---|
| [CrestApps.Core](https://github.com/CrestApps/CrestApps.Core) | AI application framework for .NET: orchestration, chat, documents, RAG, MCP, A2A, agents and reporting. |
| [CrestApps.OrchardCore](https://github.com/CrestApps/CrestApps.OrchardCore) | Modules that extend Orchard Core, built for usability, security and performance. |
| [CrestApps.AgentSkills](https://github.com/CrestApps/CrestApps.AgentSkills) | Shared AI agent skills and MCP tooling for .NET and Orchard Core projects. |
| [bootstrap-select](https://github.com/CrestApps/bootstrap-select) | Bootstrap-powered select elements with multi-selection, search and more. |
| [CrestApps.SoftPhone](https://github.com/CrestApps/CrestApps.SoftPhone) | Always-on browser soft phone for CrestApps telephony on Orchard Core. |
